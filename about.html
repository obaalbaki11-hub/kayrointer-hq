How we work

Four rules. No exceptions.

Rule 1

Run it before you sell it.

Every tool we offer, we use on our own ventures first.

Rule 2

Working software, early.

A live preview link early on, not a deck of mockups.

Rule 3

Say what we're not building.

Every scope lists what's out, so nothing surprises you later.

Rule 4

You own everything.

Code, accounts, domains and data are handed over. We stay on only if you want us to.
